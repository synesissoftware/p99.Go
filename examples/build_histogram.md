# p99.Go - Example - **build_histogram**

## Summary

Example illustrating use of `Histogram` to record event durations generated by `time.Sleep` delays under a simple PRNG, then print the histogram and percentile summary.

## Source

See [examples/build_histogram/main.go](./examples/build_histogram/main.go).

## Execution

The number of iterations can be configured via the `P99_TRIES` environment variable:

```bash
# Run with the default of 100 tries
go run ./examples/build_histogram

# Run with 1000 tries
P99_TRIES=1000 go run ./examples/build_histogram
```
